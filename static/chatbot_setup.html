HTML / Any Website
Works on any site you can edit the source of.
  1. Open your site's main HTML file (often index.html).
  2. Paste the script below just before the closing </body> tag.
  3. Save and reload the page — the chat bubble will appear in the bottom-right corner.
📝
WordPress
For self-hosted WordPress sites.
  1. In your WordPress admin, go to Appearance → Theme File Editor.
  2. On the right panel, click Theme Footer (footer.php).
  3. Paste the snippet below right before the closing </body> tag.
  4. Click Update File. Visit your site to confirm.
Tip: For a no-code option, install a plugin like "Insert Headers and Footers" and paste the snippet under "Scripts in Footer".
🟦
Wix
Add via Wix's Custom Code feature (Premium plan required).
  1. From your Wix dashboard, open Settings → Custom Code (under Advanced).
  2. Click + Add Custom Code.
  3. Paste the snippet below into the code box.
  4. Set Add Code to Pages to All pages, and Place Code in to Body — end.
  5. Click Apply.
🛍️
Shopify
Add to your storefront via theme code.
  1. From Shopify admin, go to Online Store → Themes.
  2. On your live theme, click ... → Edit code.
  3. Under Layout, open theme.liquid.
  4. Paste the snippet below directly before the closing </body> tag.
  5. Click Save.
